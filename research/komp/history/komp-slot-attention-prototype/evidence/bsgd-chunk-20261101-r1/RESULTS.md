# BSGD chunk 实测结果

868 项验收通过，24 组算子测速完成。H100 80GB，Torch 2.10.0a0，Triton 3.7.1。

## 数值验收

- torch.float32：输出、最终状态与全部输入梯度对齐独立 FP64 参考，最坏 RMS 相对误差 5.28922e-07；门槛 0.0005。
- torch.bfloat16：输出、最终状态与全部输入梯度对齐独立 FP64 参考，最坏 RMS 相对误差 0.00175112；门槛 0.015。
- 未来输入干预：216 项，最大绝对值 0。
- 前缀损失对未来输入的梯度：36 项，最大绝对值 0。
- 另覆盖 C=16/32/64、scalar/slot decay、归零衰减、beta/merge=0/1、尾块、不规则维度、D/V=128、独立输出/状态损失、任意 token 断点续接及重复中心。
- 前向的中心/系数规则与 gated 递归版一致，分块只改变计算顺序；grid-search 不适用。浮点归约与原子加法不保证逐 bit 等价或确定性。

## 同规则加速

- (2, 256, 4, 32, 32, 16)：最快 chunk16，相对同规则递归版加速 9.36×；耗时为不同算法 block KOMP 的 0.96×。
- (2, 2048, 4, 64, 64, 32)：最快 chunk16，相对同规则递归版加速 26.76×；耗时为不同算法 block KOMP 的 1.71×。
- (64, 192, 8, 64, 64, 32)：最快 chunk32，相对同规则递归版加速 1.27×；耗时为不同算法 block KOMP 的 1.62×。

中心轨迹按槽并行但槽内仍串行；geometry backward 使用原子累加。Backward 仍分配 O(BTHMV) 局部重算工作区。本轮没有 Depo/Brevo 训练收益结论。

源码、环境、验证和运行日志见当前目录。原有 KOMP kernel 未改动；公共 scan/局部 backward 复用冻结依赖。
