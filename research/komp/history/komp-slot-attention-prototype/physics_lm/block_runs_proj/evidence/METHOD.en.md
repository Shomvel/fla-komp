# Projection / SWA experiment protocol

Frozen source: frozen-20261101-proj; all SHA256SUMS checked locally before snapshot.
Main-tree experiment.py and block_experiment.py copied into an independent snapshot. Kernel sources only from the frozen tree. No kernel modification.

Seeds 731–737; 8 main arms, 56 runs. Optional FIFO C128 with/without projection, 14 runs, starts only after all main runs succeed. The same 16-worker allowance as the preceding experiment is used; first job runs all preflight checks before other jobs are submitted. First error preserves failure.json and prevents new runs; no automatic retries.

M32, C64 (C128 extension), per-slot decay. Learned eviction includes 2 sigmoid(score) write gating. No coherence, dedupe, projectron or short convolution. Block algebra runs frozen FP32 flex, with BF16 q/k/v from autocast. Deterministic algorithms, CUBLAS_WORKSPACE_CONFIG=:4096:8, TF32 disabled throughout.

SWA directly reuses KOMP q/k/v/out/gate/norm module objects initialized by the original backbone. The unused decay/beta/initial dictionary parameters are removed. Every remaining shared parameter, in every layer and the embedding/head/FFN, is hashed and compared before/after replacement; the report checks equality across arms by seed.

SWA q/k are not L2 normalized. SDPA uses dot products divided by sqrt(64), no dropout, boolean mask 0 <= query_position-key_position < W, where W includes the current position. q/k/v are BF16 under autocast; output receives the same per-head FP32 RMSNorm, SiLU output gate and output projection as KOMP. RoPE uses full 64 coordinates, adjacent pairs, base 10000, position zero at sequence start, FP32 trigonometry followed by cast to query/key dtype; values are not rotated. W192 covers the entire causal prefix of the 192-token harness. NoPE differs from W96 RoPE only by skipping the rotation. Right padding is in the causal future of valid outputs; it therefore cannot influence non-padding losses/generation queries.

Budget: 4096 persistent state elements per head for W32 and M32 (8192 per layer, 32768 over four layers); W96 12288/head; W192 24576/head. These are element counts, not memory-byte equivalence: SWA uses BF16 KV, Block uses FP32 persistent keys/coefficients, and learned eviction carries score bookkeeping. Block's live dictionary grows from M to M+C each chunk. This experiment does not implement a streaming KV cache and does not measure cache memory or kernel throughput. Recomputed full sequences follow the original generation harness. RoPE, Gaussian versus softmax readout, delta writes, learned initial atoms and active parameter count differ across families. This is a matched-backbone quality comparison under a fixed recipe, not an isolated projection-only contrast across families.

Training: width128, four layers, two heads, FF256, vocab32000; 10,001,108 nonpadding tokens, one epoch, 2231 steps, batch64, same fixed order. AdamW(.9,.95), WD.1; peak LR5e-4, warmup5%, cosine to10%, residual-output LR multiplier .1→.3. No per-family tuning. Confirm CE uses complete confirm split; generation first128 per task, greedy. Depo valid equals exact; Brevo allows valid alternative topological orders. Confirm was used in previous exploration, not a new untouched test set.

Preflight: initial and trained future-suffix intervention across window/chunk boundaries, exact repeated-forward check, 16-step loss decrease; learned score finite nonzero gradient. Each SWA mixer is separately tested outside its window and at its oldest included key. Window locality is a single-mixer property; stacking expands the receptive field. Full-attention W192 is checked on length201 for the window bound, while quality runs remain length192.

Statistics: means and sample SD, paired seeds, percentile 95% CI from 20,000 paired bootstrap draws with RNG91731. No multiplicity correction; intervals condition on fixed data/order/generation subset. Prespecified pairs: no-proj minus proj for FIFO/learned; FIFO projected minus SWA32/96; RoPE96 minus NoPE96; optional C128 no-proj minus proj. No claim that full attention is a mathematical upper bound; it is the reference achievable with this recipe.

Timing: CUDA-synchronized wall times wrap validation/evaluation/generation. Train-loop plus bookkeeping is summary elapsed minus measured evaluation and generation; checkpoint-reload evaluation is recorded separately, outside summary elapsed. This includes Python/logging overhead and is not pure optimizer-step GPU time. Flex and SDPA wall times must not be read as kernel-speed comparisons.

Interpretation: removing projection ablates one explicit cross-chunk coefficient transfer. It does not remove all older-token dependence: a retained delta coefficient was computed from a prediction involving prior memory. FIFO constrains the dictionary keys, not necessarily the full information history in coefficients; learned eviction may keep nonrecent keys. A causal result is not evidence of a strict model-wide W-token receptive field.
