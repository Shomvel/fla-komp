User-confirmed scope: Mano, Lano, Depo2, Brevo2, Capo are trained separately. Each architecture/task receives 100M non-padding next-token positions, two seeds; LR/WD is selected first from a 10M prefix on the same approximately 100M-parameter model. Batch size is 128 documents, with gradient accumulation if needed. Every mixer uses short convolution. No no-convolution arm is planned.

Architectures: native FLA GDN, GSA, GSA2; Block-KOMP per-slot FIFO with joint projection, M=32, C=128 (best prior seven-seed combined CE); RoPE full attention; RoPE SWA W=96. W=96 is a quality baseline and is not an equal-state-budget comparison. GSA2 uses its supported 64 slots; other architecture state sizes will be reported explicitly. Width512, 15 layers, FF2048, untied 32000-token input/output embeddings are the candidate common backbone. Exact parameter counts require GPU preflight; no count is asserted here.
